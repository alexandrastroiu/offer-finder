# Offer Finder App
Offer Finder App is a CLI application implemented in Java, that allows users to search, compare and filter restaurants and 
restaurant offers.
The application uses a role-based authentication system and provides different functionalities depending on the 
authenticated user's role.
It applies key Java OOP principles in a real-world inspired scenario.

## Features
**Client:**
* Search restaurants
* Search products
* Compare offers
* Filter offers by: distance, price, reviews and discount percentage

**Restaurant Manager:**
* Add offers
* Update offers
* Delete offers

**Administrator:**
* Add restaurants
* Delete restaurants
* Generate statistics

## Technologies Used
* Java
* Java Stream API
* JUnit for unit tests
